Why this scanner?

🔒

Read-only by design

Only Describe*, List*, Get* calls. Enforced by a constructor-identity allowlist — no write API is reachable.

🧮

Per-resource savings math

Hard-coded AWS price tables + multiplier formulas (idle EC2 → 60% of base cost, oversized RDS → 40%, idle EBS → 50%).

⚡

Free-plan compatible

Browser-driven chunked fan-out: each scan slice runs in its own Worker invocation, staying under the 50-subrequest limit.

📊

Live data, not estimates

Cost Explorer (grouped by service) + CloudWatch metrics (CPU, network, IOPS, traffic) over your lookback window.

🔐

Credentials never persisted

Keys stored in a Durable Object with a 30-minute alarm TTL — wiped even if the run dies. Only masked key (AKIA****MPLE) ever logged.

📥

JSON / HTML / DOCX

Reports rebuilt client-side from D1 findings. DOCX generated lazily via the docx npm package in the browser.

Services scanned

  • EC2-Instances — stopped, low CPU (<5%), underutilized (<15%), old generations (t2/m4/c4/r4)
  • EC2-Other — unattached EBS, unassociated EIPs, old snapshots (>90d)
  • RDS — stopped, low CPU/connections, oversized, old classes, prod without Multi-AZ
  • ELB — no healthy targets, near-zero requests, empty classic ELBs
  • VPC — idle NAT Gateways (<1GB), low-traffic NATs, VPN with 0 tunnels up
  • EKS — old K8s versions (<1.28), clusters with no nodegroups, m5 nodegroup sizing
  • Secrets Manager — unused secrets (no access >90d)
  • CloudWatch — log groups with no retention, high ingestion (>5GB/day)
  • S3 — idle buckets, missing lifecycle policies, versioned without expiry
